Предпросмотр
Загрузи фотоПоявятся готовые размеры

Создаются 1024×1024 (главный логотип), 512×512 (PWA), 180×180 (iPhone), 48×48 и 32×32 (favicon). Исходное фото не отправляется на сервер. Эта страница готовит файлы для скачивания, но не записывает их в GitHub автоматически.

Как заменить логотип в репозитории

После скачивания комплекта открой файлы logo.webp / logo.svg и настройки иконок в Messap. Для автоматической записи в GitHub потребуется отдельное безопасное подключение аккаунта — не вставляй токен GitHub в эту страницу.
