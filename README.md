# Faberlink

Faberlink — адаптивный русскоязычный прототип веб-мессенджера.

## Возможности
- Регистрация и вход в интерфейсе.
- Поиск локальных пользователей.
- Чаты и личные заметки «Избранное».
- Адаптация под мобильные устройства.
- PWA manifest, service worker и иконки приложения.
- Автоматическая публикация через GitHub Pages.

## Запуск локально
Откройте `index.html` в браузере. Для проверки PWA запустите локальный HTTP-сервер, например:

```bash
python -m http.server 8000
```

Откройте http://localhost:8000.

## Публикация
В репозитории выберите **Settings → Pages → GitHub Actions**. Workflow из `.github/workflows/pages.yml` публикует сайт при каждом push в `main`.

## Ограничения текущего прототипа
Аккаунты и сообщения сохраняются в `localStorage` одного браузера. Регистрация не создаёт серверный аккаунт, а сообщения не доставляются между разными устройствами или пользователями в интернете. Для настоящего мессенджера нужны backend, общая база данных, серверная авторизация и механизм доставки сообщений в реальном времени. Не храните в прототипе чувствительные данные.
